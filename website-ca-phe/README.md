# Mộc Coffee — Website bán cà phê demo

Website bán cà phê đơn giản, viết bằng HTML, CSS và JavaScript thuần; không cần cài thư viện.

## Cách mở trên máy tính

1. Tải repository về máy hoặc mở thư mục dự án đã clone.
2. Mở thư mục `website-ca-phe`.
3. Nhấp đúp vào `index.html` để mở bằng trình duyệt.

## Tính năng

- Giao diện tiếng Việt, tương thích điện thoại và máy tính.
- Hiển thị 3 sản phẩm mẫu với giá tham khảo.
- Thêm sản phẩm vào giỏ, giảm số lượng và tính tổng tiền.
- Nhập tên, số điện thoại, địa chỉ và ghi chú.
- Tạo nội dung đơn hàng để sao chép.

## Lưu ý

Đây là bản demo giao diện. Đơn hàng chưa được gửi đến cửa hàng hoặc lưu trên máy chủ; chưa có thanh toán trực tuyến. Giá, hình ảnh và thông tin sản phẩm là dữ liệu mẫu, cần cập nhật trước khi sử dụng kinh doanh thật.

## Đăng lên GitHub Pages

Có thể cấu hình GitHub Pages để xuất bản thư mục này. Vì trang nằm trong thư mục `website-ca-phe`, cần chọn cách triển khai thư mục đó làm thư mục xuất bản; chỉ bật Pages ở thư mục gốc sẽ không tự động dùng trang này.
